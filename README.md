BETON BRUT — ПРОТОТИП ПРИЛОЖЕНИЯ ОТЕЛЯ
======================================

Единое приложение для гостей и персонала: заказ в номер (iiko), спа-запись (1С:СПА), сервисы и цифровой ключ (1С:Отель), программа лояльности, чаевые, промокоды, пуш-уведомления.
